News App
A dynamic news dashboard designed to display news updates in a carousel format, ideal for large screens during department functions. The app integrates NewsAPI for real-time news and uses React.js for a responsive and interactive UI.

Features
Dynamic News Carousel: Display headlines, descriptions, and images with smooth transitions.
Real-Time News: Fetch live news updates using NewsAPI.
Responsive Design: Optimized for large dashboard screens.
Customizable: Tailored for department-specific functions and events

Tech Stack
Frontend: React.js, CSS
API: NewsAPI
